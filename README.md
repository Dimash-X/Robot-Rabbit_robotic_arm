# Robot Rabbit (Simple two joint mechanical arm)

A beginner-friendly robotics project featuring a simple robotic arm with two rabbit-ear-like grippers, designed to pick up objects of different sizes and move them from one place to another. Built about a year ago, this project is intentionally simple and accessible to complete beginners in mechatronics. This repository aims to help young learners get started with robotics through step-by-step instructions for building their first simple robotic mechanism.
